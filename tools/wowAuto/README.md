# wowAuto

根据 wowDetector 插件色块发送按键的 Windows 图形化工具。

## 文件

- `wowAuto.bat`：双击打开图形窗口，仅为本次 PowerShell 进程放行脚本执行策略。
- `wowAuto.ps1`：窗口、取色、前台状态检查及按键执行。
- `wowAuto.Engine.ps1`：统一任务队列和定时事件调度。三个文件需放在同一目录。

## 使用

1. 在游戏中启用 wowDetector，点击“启动”或输入 `/wowdetector on`，插件会自动将色块居中并锁定位置；关闭检测后自动解除锁定。
2. 双击同目录或桌面的 `wowAuto.bat`。在 `autofish` 标签页点击“刷新进程”，工具依次将游戏窗口切到前台，检测客户区正中心；只有红色或绿色通过后才开放该行控制按钮。
3. 每行显示窗口标题和PID，并横向排列等待范围、开始、停止和实时状态。每个进程可分别输入范围，单位为ms，默认8000和13000。接受1–3600000的整数，最小值不得大于最大值；相等时固定等待。
4. 点击标签页内“全部开始”，将所有符合要求的行加入统一队列；也可以只点击单行“开始”。松开修饰键，工具会自动切换游戏窗口。每行状态框显示排队、下竿、定时收竿、倒计时及异常。
5. “全部停止”取消所有任务和定时事件；单行“停止”只取消对应任务。运行中该行范围输入锁定，停止后可修改。关闭工具窗口会停止所有任务。更新后需关闭旧实例再打开新版。

刷新前停止所有行并取消等待，保留仍存在进程的范围设置，新增默认停止行，移除已退出进程。逐行扫描先等待约200ms，未识别时重试至800ms；扫描结束尝试切回原窗口。黄色、灰色、未知颜色、无法获得焦点或读取进程信息时不开放按钮。刷新扫描不会发送按键，也不会因为黄色结束游戏。扫描后需手动重新开始通过检测的行。

使用PID与启动时间一起识别进程，避免新进程复用旧PID时继承旧任务。没有游戏进程时显示0行。

## 统一调度

工具使用一个共享时钟和事件队列，串行操作窗口：

1. 选择一个待下竿窗口并切到前台，确认焦点后读取中心颜色。
2. 红色时按随机300–600ms周期重复Ctrl+1（相邻周期不同），留在当前窗口，直到变绿。
3. 绿色时按该行范围生成毫秒等待值，登记收竿事件，立即轮到下一个待下竿窗口；后台等待不会取消事件。
4. 每次调度先检查已到期收竿事件，按到期时间、登记顺序优先执行，能够中断当前下竿或窗口切换。切到事件对应的窗口并确认焦点后发送一次Ctrl+2。
5. 从Ctrl+2释放后计时1000ms，该行重新加入下竿队列；这1秒不阻塞其他窗口。

灰色或未知颜色暂不按键，稍后重新排队。窗口切换或进程验证失败只停止对应行。窗口切换需等待画面稳定（约200ms）；实际发送时间还受Windows调度和切换耗时影响，不保证毫秒级实时性。

## 颜色与操作

| 颜色 | 操作 |
| --- | --- |
| 红色 | 重复发送 Ctrl+1 直到变绿；到期收竿事件优先 |
| 绿色 | 登记随机毫秒收竿事件，转到下一个待下竿窗口 |
| 黄色 | 核对进程名和启动时间后，只结束该行对应的游戏进程并停止该行；其他行继续运行 |
| 灰色或无法识别 | 不操作 |

在窗口被调度到前台时检查黄色；后台等待期间不会持续取色。停止、刷新和关闭工具会移除对应待执行事件，重新开始不会继承旧计时。

插件黄色表示随身普通背包空格为0，不计银行、材料袋、专用袋，也不估算现有物品剩余堆叠容量。窗口遮挡、隐藏UI等情况可能影响取色。

## 同步与兼容

从仓库根目录按“检查 → 提交 → 推送”顺序完成修改，再运行 `skills/wow-tools/scripts/sync-local.ps1`。完整维护流程见 [维护技能](../../skills/wow-tools/SKILL.md)。

同步脚本将此目录的三个运行文件安装到 Windows 桌面。旧 `wow-foreground-loop.bat` 和 `.ps1` 入口转发到新版，覆盖前文件备份在仓库 `.local-backups` 中。插件同步至游戏的 `Interface\AddOns\wowDetector`。

## 验证

运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Engine.Tests.ps1` 验证队列顺序、到期抢占、轮询、等待和取消，不发送按键或终止进程。`wowAuto.ps1 -PreviewPath <绝对PNG路径>` 渲染初始窗口。在源码目录加 `-UiTest` 执行 `tests/Refresh.UiTests.ps1` 和 `tests/Scheduler.UiTests.ps1`，用模拟进程验证刷新、全部开始/停止、调度和计时；不调用真实前台切换、取色、按键或结束进程接口。
