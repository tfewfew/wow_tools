# wowAuto

根据 wowDetector 插件色块发送按键的 Windows 图形化工具。

## 文件

- `wowAuto.bat`：双击打开图形窗口，仅为本次 PowerShell 进程放行脚本执行策略。
- `wowAuto.ps1`：窗口、取色、前台状态检查及按键执行。
- `wowAuto.Engine.ps1`：运行状态和计时逻辑。三个文件需放在同一目录。

## 使用

1. 在游戏中启用 wowDetector，点击“启动”或输入 `/wowdetector on`，插件会自动将色块居中并锁定位置；关闭检测后自动解除锁定。
2. 双击同目录或桌面的 `wowAuto.bat`。`autofish` 标签页按当前 `WowClassic.exe` 进程生成控制行，全局“刷新进程”按钮更新进程数量和列表。
3. 每行显示窗口标题和PID，并横向排列等待范围、开始、停止和实时状态。每个进程可分别输入范围，单位为ms，默认8000和13000。接受1–3600000的整数，最小值不得大于最大值；相等时固定等待。
4. 点击对应行的“开始”，松开修饰键并切回对应游戏。保持画面正中心色块可见。该行状态框显示暂停、检测、倒计时及异常。
5. 点击某行“停止”只取消该行的等待，其他行不受影响。运行中的行锁定自己的范围输入，停止后可修改。关闭工具窗口会停止所有行。更新后需关闭旧实例再打开新版。

刷新会保留仍存在进程的范围和运行状态，为新进程添加默认停止的行，停止并移除已退出进程的行。使用PID与启动时间一起识别进程，避免新进程复用旧PID时继承旧任务。没有游戏进程时显示0行并提示启动游戏后刷新。

脚本只检测游戏客户区正中心，不主动切换窗口。只有当前前台游戏对应的行可以发送按键；后台行每500ms检查一次并取消未完成的等待，切回该游戏后从颜色检测重新开始。

## 颜色与操作

| 颜色 | 操作 |
| --- | --- |
| 红色 | 发送 Ctrl+1 |
| 绿色 | 在输入范围内随机等待整数毫秒，发送一次 Ctrl+2，发送完成后等待1000ms再恢复颜色检测 |
| 黄色 | 核对进程名和启动时间后，只结束该行对应的游戏进程并停止该行；其他行继续运行 |
| 灰色或无法识别 | 不操作 |

正常颜色检测周期随机300–600ms，相邻周期值不同。收竿前等待期间每500ms检查前台状态及黄色，临近截止时间提前唤醒，避免把随机等待取整成500ms。Ctrl+2发送后的1000ms暂停期间不检测颜色。

插件黄色表示随身普通背包空格为0，不计银行、材料袋、专用袋，也不估算现有物品剩余堆叠容量。窗口遮挡、隐藏UI等情况可能影响取色。

## 同步与兼容

从仓库根目录按“检查 → 提交 → 推送”顺序完成修改，再运行 `skills/wow-tools/scripts/sync-local.ps1`。完整维护流程见 [维护技能](../../skills/wow-tools/SKILL.md)。

同步脚本将此目录的三个运行文件安装到 Windows 桌面。旧 `wow-foreground-loop.bat` 和 `.ps1` 入口转发到新版，覆盖前文件备份在仓库 `.local-backups` 中。插件同步至游戏的 `Interface\AddOns\wowDetector`。

## 验证

运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Engine.Tests.ps1` 检查状态和计时逻辑，不发送按键或终止进程。`wowAuto.ps1 -PreviewPath <绝对PNG路径>` 可渲染初始窗口，保持未启动状态。加 `-UiTest` 使用模拟进程测试独立行、按钮绑定、刷新保留和PID复用，始终禁用实际输入定时器。
