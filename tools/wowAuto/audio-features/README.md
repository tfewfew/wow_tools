# 咬钩声音特征

运行时读取 `titan.feature`（时光服）或 `forerver.feature`（无限服），按进程所属版本选择。只保存数值特征，不保存录音；两服分别采集，不能互用。

无限服已接入2026-10-11授权采集的40秒录音中第31.199秒的一个候选片段（抛竿约22.3秒后）。用户未能确认声音类别，明确授权先集成试用，因此标记为 `trial`，不能视为已确认的咬钩样本。当前门槛93%，实际误报和漏报待游戏内反馈。

同一录音的离线帧回放在第31.239秒触发一次，相似度97.5981%；这一结果只验证候选能进入实时匹配流程，不是独立准确率测试。录音中只有一轮约30秒引导，无提前收竿、无重复咬钩样本。时光服尚无特征，取消音频勾选仍可使用定时模式。

文件使用 `key=value`，支持空行及 `#` 整行注释：

- `Format=1`
- `SampleRate=11025`
- `WindowSamples=4096`
- `Status`：`trial`（未确认或试用）/ `verified`（已确认），省略时按trial处理；运行中试用特征显示“试用匹配”。
- `Threshold`：校准后的相似度门槛，0.5–1。
- `Template`：32个逗号分隔的有限非负数，前24项为归一化频谱，后8项为归一化音量包络。可重复1–8行，分别代表同一咬钩音效的变体。

缺失、损坏或格式不支持时，对应版本的音频任务不能启动。不使用合成测试数据冒充实际特征；原始长录音和离线分析工具留在本地忽略目录。
