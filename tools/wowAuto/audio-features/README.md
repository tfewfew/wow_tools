# 咬钩声音特征

运行时按进程版本读取 `titan.feature`（时光服）或 `forerver.feature`（无限服）。两服分别采集，只保存数值特征；原始录音、候选片段及离线分析工具留在本地忽略目录。

两份特征均来自2026-10-11各自授权录制的180秒音频，均为 `Status=trial`。时光服从10轮重复候选中，用前3轮生成一个共同特征，后7轮只做验证；无限服用3段生成共同特征，另3段只做验证。对齐后的整体频谱、分段频谱和音量包络分别求平均并归一化，不直接平均PCM波形。完整采集与离线验证说明见上一级README。

两服特征推荐门槛90%，实际匹配使用设置及 `config.ini` 中各服门槛，目前均为86%。相似度是匹配分数，不能视作钓获成功率；还需绿色状态、一秒预热及音量突变门槛。一次会话中的验证不能证明跨地点或其他玩家声音的识别准确率。

文件使用 `key=value`，支持空行及 `#` 整行注释：

- `Format=2`
- `SampleRate=11025`
- `WindowSamples=11025`：完整一秒窗口。
- `SpectrumBands=24`、`TimeSlices=8`、`EnvelopeBins=16`。
- `Status`：`trial`（试用）或 `verified`（已确认），省略时按trial处理；运行中试用特征显示“试用匹配”。
- `Threshold`：推荐相似度门槛，0.5–1；不覆盖用户设置。
- `Template`：232个有限非负数，依次为24项整体频谱、192项时序频谱、16项音量包络；三组各自归一化。可重复1–8行，表示同一音效的变体；目前两服各有一个共同特征。

缺失、损坏或格式不支持时，阻止对应版本的音频任务启动；取消音频勾选仍可使用定时模式。旧格式1不再支持，必须从原始素材重新生成。不得用合成测试数据充当实测特征，也不得把一服特征套用于另一服。
